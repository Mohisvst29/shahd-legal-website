# موقع المستشارة القانونية شهد إبراهيم محرم ⚖️

منصة ويب قانونية متكاملة للمستشارة والباحثة القانونية **شهد إبراهيم محرم** (حاصلة على بكالوريوس القانون من جامعة الملك عبد العزيز بمرتبة الشرف الأولى وخبرة تزيد عن 4 سنوات في الاستشارات، دراسة القضايا، إعداد اللوائح وصياغة الطعون والعقود).

---

## 🌟 مميزات المنصة الرئيسية

1. **الواجهة الرئيسية التفاعلية (`index.html`):**
   - هوية بصرية فاخرة وألوان ملكية كحلية مع درجات الذهب الفاخر.
   - تأثيرات حركية وترانزليشن وتوهج تفاعلي يتبع حركة الفأرة.
   - قسم النبذة التعريفية والسيرة المهنية والمؤهلات الأكاديمية.
   - ركائز العمل القانوني وأقسام مجالات الممارسة والخدمات.
   - حاسبة تقدير التكاليف ومؤشرات الخدمات القانونية.
   - نموذج حجز المواعيد والاستشارات القانونية المتزامن.
   - بوابة الموكلين للاستعلام وتتبع مسار القضايا برقم المرجع.
   - نافذة الأسئلة الشائعة وتذييل رسمي متكامل.

2. **صفحة الشكر وتأكيد الحجز (`thank-you.html`):**
   - إشعار مؤكد بحالة الطلب والرقم المرجعي المعتمد (`SH-2026-XXXX`).
   - بطاقة تفاصيل الموعد والخدمة ومعلومات التواصل.
   - إمكانية نسخ رقم المعاملة بنقرة واحدة.
   - طباعة إشعار الاستلام بصيغة رسمية أو حفظه كـ PDF.
   - تأكيد الموعد عبر الواتساب برسالة مسبقة التجهيز.
   - زر مباشر للانتقال إلى بوابة الموكلين ومتابعة الطلب فوراً.

3. **لوحة التحكم والإدارة الشاملة (`admin.html`):**
   - إدارة طلبات الاستشارات والمواعيد وتغيير حالاتها.
   - متابعة وتحديث مراحل القضايا في بوابة الموكلين.
   - إدارة وتحديد الأوقات والمواعيد الشاغرة للاستشارات.
   - التحكم في الشعار، حجمه، ونمط العرض والدمج.
   - التحكم في روابط التواصل الاجتماعي ورقم الواتساب.
   - إدارة وسائط وصور الموقع ومعرض آراء الموكلين.

---

## 💻 التقنيات المستخدمة
- **HTML5 & CSS3** مع بنية دلالية وتنسيقات مخصصة.
- **Tailwind CSS** للتصميم العصري والتجاوب مع جميع الشاشات.
- **Vanilla JavaScript (ES6+)** لمنطق الحجز، التتبع، والتخزين المحلي.
- **FontAwesome & Google Fonts** (Cairo, Amiri, Cinzel).

---

## 🚀 التشغيل محلياً
يمكن تشغيل الموقع باستخدام أي خادم محلي:
```bash
python -m http.server 8080
```
ثم فتح المتصفح على: `http://localhost:8080/`
